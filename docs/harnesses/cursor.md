# Cursor

Select `HARNESS=cursor` and set `AGENT_COMMAND` to the installed `cursor-agent`
executable. The gateway launches `acp` mode. Authenticate that client separately
and preserve its native profile/session location across gateway upgrades.

Cursor model/effort choices use its native model IDs and variants. The gateway
handles its load/rehydration behavior and native permission/event forms.
`/mcps` calls `mcp list`, or `mcp list-tools` for a selected server.

Grok passthrough commands are unavailable. Interactive questions and plan requests
receive skipped/rejected responses; the transport does not expose a terminal UI.
Steering requires an advertised capability rather than a provider-name assumption.
